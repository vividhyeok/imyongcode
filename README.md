# ImyongCode

정보·컴퓨터 임용 대비용 **C / Python 빠른 복습 + 진단 웹앱**입니다.

PDF처럼 처음부터 끝까지 읽는 방식이 아니라 다음 흐름으로 사용하도록 만들었습니다.

1. **10초 훑기** — 질문만 보고 바로 기억나면 넘기기
2. **한 문제씩 진단** — 실행하기 전에 출력/코드를 먼저 작성
3. **MyCompiler 확인** — 작성형 문제는 복사 후 외부 컴파일러에서 확인
4. **자가 판정** — 바로 풀림 / 헷갈림 / 틀림
5. **약점 자동 수집** — 문제 번호와 문법 영역을 자동 정리
6. **ChatGPT 보강 프롬프트 복사** — 약한 부분만 30~40분짜리 추가 복습으로 이어가기

## 특징

- C 10초 복습 카드
- Python 10초 복습 카드
- C01~C15 진단
- P01~P15 진단
- 코드/출력 답안 입력 저장
- localStorage 기반 진행도 저장
- 약점 자동 집계
- 약점 기반 ChatGPT 프롬프트 생성
- 다크/라이트 테마
- 모바일 대응
- 진단 단축키: `1` 바로 풀림 / `2` 헷갈림 / `3` 틀림 / 방향키 이동

## 실행

별도 빌드 과정이 없는 정적 웹앱입니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 학습 기준

목표는 C/Python을 완벽하게 다시 배우는 것이 아니라, 오래된 문법 기억을 빠르게 활성화하고 **컴파일러 없이 짧은 코드를 종이로 추적하는 감각**을 복구하는 것입니다.

진단이 끝나면 C/Python 자체를 오래 붙잡기보다 자료구조·운영체제로 넘어가 코드 추적을 계속하는 것을 전제로 합니다.
